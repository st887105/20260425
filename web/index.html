LINE 傳檔卡住了嗎？

在發生問題的電腦按下「一鍵修復」，會改用學網備援 DNS，讓 LINE 傳圖、傳檔走 IPv4。不用輸入指令，也不用自己改網路卡設定。

一鍵修復 LINE 傳檔

IPv4 DNS → 163.24.239.2　IPv6 DNS → 2001:288:8600:1::1002
完成後會跳出結果視窗，並在背景記錄網路狀況 30 分鐘，有異常會自動通知資訊老師。

🛠️ 一鍵修復 只監測、不改設定

↩️ 還原 DNS 設定

網頁連線檢查

測試瀏覽器能否連到本網站並記下回應時間，可以在還沒安裝小幫手的電腦上使用。

前往上傳結果

檢查完成後可按「前往上傳結果」，用校方管理帳號登入後確認上傳。網頁檢查只能測本網站的連線，完整的 DNS 與 IPv6 資料請用上方的小幫手。

按了沒反應？
  1. 瀏覽器若詢問「要開啟 車城國小 LINE 小幫手 嗎？」，請選「開啟」。
  2. 完全沒反應，表示這台電腦還沒安裝小幫手，請先用上方「網頁連線檢查」，再聯絡資訊老師。
  3. 資訊老師安裝方式：在該電腦執行 install.bat（只需一次，要有管理員權限）。
